# mcvcgames.github.io

The MCVC Games website, served by GitHub Pages at https://mcvcgames.github.io/: the studio page and each game's privacy policy and terms of service (Arcanomaly: `arcanomaly/privacy.html`, `arcanomaly/terms.html`).
